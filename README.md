# bejuwt Homebrew tap

## PingViewScan

Multi-host ping monitor and graphical network scanner for macOS.

```sh
brew install --cask bejuwt/tap/pingviewscan
```

The cask clears the quarantine flag after install, so the app launches without a
Gatekeeper prompt (PingViewScan is ad-hoc signed and not notarized).

To upgrade:

```sh
brew upgrade --cask pingviewscan
```

To remove:

```sh
brew uninstall --cask pingviewscan
```
